Connection Mode

⚠ Browsers can only connect to MQTT via WebSocket. To enable it in Mosquitto, add to mosquitto.conf: listener 9001 then protocol websockets, then restart the broker.

Edit the channels array as JSON. See config.json.example for the format.
ℹ️ Can I use Spotify?

No. Spotify audio is DRM-protected and its Web API does not expose the raw audio samples required by the visualizer. Use local MP3/FLAC/WAV files instead.
